Input Module

The input module provides functions and constants to query the keyboard, mouse or gamepad. It also provides functions to get frame-related timing data.

Functions

Function Description
getDeltaTime() Return the time elapsed since the last frame in milliseconds.
getFrameRate() Return the current GPU frame rate.
getMouseDrag() Return the amount the mouse has moved since the last frame as a Vec2.
getMousePos() Return the current mouse position as a Vec2.
getTime() Return the number of milliseconds since the start of the program.
hasMouseMoved() See if the mouse moved in the last frame.
isButtonDown() See if a keyboard, mouse or gamepad button is down (use the enum below to address to query specific button).
isButtonPressed() See if a keyboard, mouse or gamepad button was pressed (use the enum below to address to query specific button).
isButtonReleased() See if a keyboard, mouse or gamepad button was released (use the enum below to address to query specific button).
isDoubleClicked() See if a keyboard, mouse or gamepad button was double clicked (use the enum below to address to query specific button).
